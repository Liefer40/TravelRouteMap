# 日本全国 陸・鉄・空・海・バス 旅の軌跡マップ — AIエージェント引き継ぎ仕様書 (HANDOVER.md)

## 1. プロジェクト概要・目的
日本国内（海外は対象外）のすべての移動・訪問の軌跡を単一のWebアプリケーション上で一元管理・可視化する、オフライン/ローカル動作可能なインタラクティブGISマップシステム。
国土交通省「国土数値情報」の各種オープンデータ（N03, N05, N07, N09, C28）をベースに、ユーザーが訪れた市区町村や乗車・搭乗・乗船した区間（セグメント）および拠点（駅・空港・港・バス停）を視覚的に塗りつぶし、制覇率を集計できる。

---

## 2. システムアーキテクチャ・技術スタック
* **フロントエンド**: Vanilla HTML5 / CSS3 / JavaScript (ES6+)
  * 外部フレームワーク（React/Vue等）は使用せず、軽量・高速でローカル環境（`file://` または簡易ローカルサーバー）で完結する構成。
  * **地図エンジン**: Leaflet.js (`v1.9.4`) — 高速描画のため `preferCanvas: true`（`L.canvas` レンダラー）を使用。
  * **ポリゴン変換**: `topojson-client@3`（全国の市区町村境界データ N03 TopoJSON の展開用）。
* **データ前処理パイプライン (Python)**:
  * Python 3.12 + `geopandas`, `shapely`
  * 国土数値情報「鉄道時系列データ（N05）」の `.geojson`（または `.shp`）から、全国の現役路線および1950年（昭和25年）以降の全廃線・部分廃線の高精細曲線（`LineString`）と駅座標を抽出し、`rail_master_n05.json` を生成するスクリプト（`build_rail_data.py`）。
* **クライアントサイド永続化**:
  * **IndexedDB (`JapanRailMapCacheDB`)**: 容量の大きい `rail_master_n05.json`（全国約1,486路線・高精細座標データ）をブラウザ内にキャッシュし、2回目以降の起動を瞬時に行う。
  * **localStorage**: ユーザーの訪問・乗車ログを6つのキーで永続化。また、全データを単一のJSONファイル（`version: 3`）としてエクスポート／インポート可能。

## 4. これまでに解決した重要課題と「絶対に壊してはいけない」技術的ガードレール

**【⚠️ AIエージェントへの重要指示】**
リファクタリングや機能追加を行う際、以下の6つの解決済みロジック（ガードレール）を絶対に退行（デグレード）させないこと。

### ① N05データの文字化け対策（UTF-8 / CP1252 ハイブリッド復元）
* **背景**: 国土数値情報（N05）のシェイプファイルや一部データを読み込む際、UTF-8バイト列が `latin1` / `cp1252` として誤解釈され文字化け（`å±±...`）する問題があった。さらに廃線サフィックス ` (〜1988廃止)` のような正常な日本語が結合されると、単純な文字列判定では修復がスキップされる問題があった。
* **対策済仕様**: `build_rail_data.py` 内の `MOJIBAKE_PATTERN` 正規表現により、文字列内の文字化けチャンクのみをピンポイントで抽出し、`cp1252` / `latin1` バイト列へ戻してから `utf-8` デコードする処理を実装済み。

### ② 本線・支線のワープ直線防止と、Y字分岐・途中途切れの完全解消（グラフDijkstra探索）
* **背景**:
  * 東海道線の「本線（東京〜熱海）」と「品鶴線（武蔵小杉経由）」のような別ルートを単純結合すると、相模湾の海上を斜めに横断する「熱海 ⇔ 武蔵小杉」のワープ直線が発生した。
  * 逆に `linemerge` だけでブランチ分割すると、鶴見線（浅野駅・安善駅・武蔵白石駅）、南武支線（尻手駅）、小田急江ノ島線（相模大野駅や途中区間）で分岐駅が片方の線路にしか所属できず、支線区間が消滅・途切れる問題が発生した。
  * また、札沼線の「太美〜当別」など、2022年に駅名改称された駅（旧：石狩太美・石狩当別、`endYear: 2021`）が現役グラフに混入すると、探索が旧駅名ノードで遮断されて現役区間が途切れる問題があった。
* **対策済仕様 (`build_rail_data.py` v5)**:
  1. `linemerge` による1本化を廃止し、`SNAP_GRID = 25000`（約4.5m精度）で元の滑らかな曲線頂点を保持したまま線路ネットワークグラフを構築（カクカク防止のため `simplify` は `0.00003` に抑制）。
  2. 現役路線は厳密に `endYear == 9999` の現役駅のみを候補とし、改称前の旧駅名の混入を排除。
  3. 各駅から線路グラフ上で「途中に他の駅を挟まずに到達できる隣接駅」を **Dijkstra法** で探索（開始ノード自身 `u == start_node` に別駅が重なっている場合は遮断せず通過許容）し、実際の線路曲線を切り出す方式により、ワープゼロ・分岐欠落ゼロを実現。

### ③ 部分廃止路線の救出と「現役区間の優先描画」
* **背景**: 留萌本線（2016年留萌〜増毛廃止、2023年石狩沼田〜留萌廃止）のように段階的に部分廃止された路線は、廃止年ごとのデータに当時の現役区間（深川〜石狩沼田）も含まれており、廃線レイヤーをONにすると現役区間まで廃線色（セピア色）で上書きされる問題があった。
* **対策済仕様 (`buildRailwayLayers`)**:
  1. まず全現役路線の駅間ペア（`activeSegmentPairs`）と現役駅キー（`activeStationKeys`）を収集する。
  2. 廃線・部分廃線データを構築する際、`activeSegmentPairs` に既に存在する区間はスキップし、現役区間に廃線色が重なるのを100%防止する。

### ④ 現役路線と廃線の「同一Canvasレンダラー共有」によるクリック貫通保証
* **背景**: `railAbandonedRenderer` と `railActiveRenderer` を別々の `L.canvas()` インスタンスに分けると、上層の `<canvas>` 要素がマウスイベントを遮断し、下層の廃線がクリック・ホバーできなくなる（LeafletのCanvas仕様）。
* **対策済仕様 (`initMap` & `updateAllRailStyles`)**:
  * **`railAbandonedRenderer = railActiveRenderer;` として必ず同一の `L.canvas` インスタンスを共有させること。**
  * 重なり順（Zオーダー）は、`updateAllRailStyles()` 内で「①廃線を描画 ➔ ②現役路線を描画して `.bringToFront()` ➔ ③駅マーカーを `.bringToFront()`」の順で制御することで、見た目上の現役優先と廃線のクリック可能性を両立している。

### ⑤ 「2024年〜2026年 最新廃線パッチ」の非破壊リアルタイム適用
* **背景**: 国土数値情報（N05）の最新公開データは2023〜2024年時点のため、直近の廃止区間が現役（`9999`）として残っている。
* **対策済仕様 (`applyRecentAbolishedPatches`)**:
  * JSON生データを書き換えることなく、ブラウザ起動時にメモリ上で以下の最新廃線パッチを自動適用する：
    1. **JR北海道 留萌本線（深川〜石狩沼田）**: 2026年3月末廃止（`FULL_LINE` 廃線化）
    2. **JR北海道 根室本線（富良野〜新得）**: 2024年3月末部分廃止（`PARTIAL_SPLIT` により滝川〜富良野・新得〜根室を現役維持し、富良野〜新得間のみを廃線として分離）
    3. **スカイレールサービス 広島短距離交通瀬野線**: 2024年4月末廃止（`FULL_LINE` 廃線化）
    4. （オプション切替対応）2027年春廃止届提出済の **JR津軽線（蟹田〜三厩）**・**JR久留里線（久留里〜上総亀山）** の先取り廃線化。

### ⑥ 正式名称（N05）⇔ 旅客案内名称（通称・愛称）の動的切替
* **背景**: N05データは鉄道事業法上の届出名（例：「東日本旅客鉄道（旧国鉄） 赤羽線」「札沼線」「常磐新線」）で収録されている。
* **対策済仕様 (`enrichLineWithPassengerName` & `getLineDisplayName`)**:
  * セーブデータの互換性を守るため、**内部キー（`line.name` や `seg.id`）はN05原典のまま変更しない**。
  * UI表示（路線一覧、詳細パネル見出し、絞り込みバナー、**地図上の路線・駅ツールチップ**）およびキーワード検索（`line.searchText`）のみ、`getLineDisplayName(line)` を通して「旅客案内名＋正式名併記」「旅客案内名優先（JR各社表記もスリム化）」「正式名称（N05原典）」の3モードで動的に切り替える。
